| Term | Meaning |

| Nimbus Notes | Our note-taking app. v1 launched 2024; v2.0 is this launch. |
| Vault sync | v2.0 feature: end-to-end encrypted sync across devices. "End-to-end encrypted" means only the user's devices can read the notes — we cannot. |
| Smart capture | v2.0 feature: share any webpage/PDF into Nimbus and it extracts a clean, searchable note. |
| Workspaces | v2.0 feature: shared folders for small teams (up to 10 people). |
| EAP | Early Access Program — the ~400 users who have been testing v2.0 since May. |
